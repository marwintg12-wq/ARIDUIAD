ChatGram — Android prototype (v0.3)

Возможности прототипа:
- регистрация по телефону или email с тестовым кодом на экране;
- локальные профили, аватары, username, группы и каналы;
- локальная отправка текста, фото, видеофайлов и аудиофайлов;
- пробная запись голосового сообщения (если WebView/Android разрешает микрофон);
- демонстрационные экраны голосового и видеозвонка;
- демо-админ-панель, роли, верификация, Premium и звёзды.

ВАЖНО: это офлайн-прототип на одном устройстве. Чаты и медиа хранятся локально в браузерном хранилище. Звонки пока являются демонстрационным экраном, а не реальным соединением. Для реальных сообщений между разными устройствами, SMS/email-кодов, звонков WebRTC, синхронизации, безопасной админки и выдачи прав необходим сервер, база данных, аутентификация и серверная проверка ролей. Не используйте демо-коды и локальные роли для реального сервиса.

Сборка через GitHub Actions: загрузите содержимое проекта в корень репозитория. Workflow ожидает ZIP с именем ARIDUIAD_GitHub_Ready.zip, если используется старый workflow.
